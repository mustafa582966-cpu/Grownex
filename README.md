# Grownex AI Video Portfolio

A responsive, premium dark portfolio website for Grownex AI video services. Built with plain HTML, CSS, and JavaScript, ready for GitHub Pages.

## Files
- `index.html` — main portfolio page
- `style.css` — responsive styling
- `script.js` — mobile navigation and footer year
- `assets/videos/` — add your 3–4 MP4 portfolio videos here
- `assets/poster-*.svg` — custom placeholder covers shown before videos load

## Add your videos
Put your MP4 files in `assets/videos/` and use these exact names:
1. `bag-ad.mp4`
2. `perfume-ad.mp4`
3. `cafe-ad.mp4`
4. `brand-film.mp4`

If your videos have different names, edit the matching `<source src="...">` paths in `index.html`. Keep video file names simple and lowercase. MP4 (H.264) is recommended. Keep files reasonably compressed for faster loading.

**Note:** This ZIP includes four ready-to-use video slots, not the actual video files. Add your own exported videos to the folder above.

## Update contact links before publishing
In `index.html`, replace:
- `91XXXXXXXXXX` in the WhatsApp URL with your phone number including country code, without `+` or spaces.
- `https://www.instagram.com/` with your Grownex Instagram profile URL.

## Publish on GitHub Pages
1. Extract this ZIP.
2. Open your GitHub repository and upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the repository root.
3. Upload your MP4 files to `assets/videos/`.
4. In GitHub, open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select your main branch and **/(root)**, then Save.
6. Wait for deployment and open your GitHub Pages URL. Refresh after deployment finishes.
